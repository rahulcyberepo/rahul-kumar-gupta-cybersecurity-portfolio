01 / About

Depth over hype.

I’m building depth, not a tool list.

I’m building my cybersecurity portfolio around penetration testing, VAPT, security analysis and application security.

My previous work with websites, analytics, troubleshooting and communicating findings has given me useful habits in investigation, problem-solving and documentation.

I now apply those skills to security while treating cybersecurity as a separate technical discipline that must be proven through hands-on labs, projects, testing, research and clear evidence of what I find and how it can be fixed.

Right now I’m strengthening networking, Linux, Windows, web security, Active Directory, Python automation and professional security reporting.
